# Rendering (domain)

Part of the `satisfactory-modding` skill. Open this domain only when the mod draws into textures: a map, a chart, a preview, an overlay. Injecting UI into game windows is core (`references/ui.md`). Markers: no marker = verified in practice, **[source]** = read from SML or game code, not tested, **[?]** = uncertain. Replace the parts in `<...>` with your own.

| Topic | File |
|---|---|
| Graphics card memory, texture size, your own canvas, drawing in batches, blend modes, reading back, PNG export, a render target without a renderer | `domains/rendering/render-targets.md` |

New findings of this domain go to `learned/rendering.md`.
