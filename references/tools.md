# Tools and scripts

Part of the `satisfactory-modding` skill. Markers: no marker = verified in practice, **[source]** = read from SML or game code, not tested, **[?]** = uncertain. Replace the parts in `<...>` with your own.

## Tools and scripts

**Following the game log (PowerShell).** Waits for the game, prints new matches and exits together with the game. Handles log rotation.
```powershell
$log = "$env:LOCALAPPDATA\FactoryGame\Saved\Logs\FactoryGame.log"
$pattern = 'LogMyMod|LogSatisfactoryModLoader|Fatal error|World Serialization'
while (-not (Get-Process FactoryGameSteam-Win64-Shipping -EA SilentlyContinue)) { Start-Sleep 2 }
$seen = 0
while ($true) {
    $running = Get-Process FactoryGameSteam-Win64-Shipping -EA SilentlyContinue
    $lines = @(Select-String -Path $log -Pattern $pattern -CaseSensitive -EA SilentlyContinue)
    if ($lines.Count -lt $seen) { $seen = 0 }            # the game rotated the log
    $lines | Select-Object -Skip $seen | % { $_.Line }
    $seen = $lines.Count
    if (-not $running) { break }
    Start-Sleep 2
}
```

**Waiting for packaging to finish:**
```bash
until grep -qE "Result: (Succeeded|Failed)" package.log; do sleep 3; done
```

**Reading Oodle-compressed data outside the game** (e.g. your own cache). The `FOodleCompressedArray` format: int32 size after decompression, int32 compressed size, Oodle stream. The library `oo2core_9_win64.dll` is in `<UE-CSS>\Engine\Binaries\DotNET\AutomationTool\AutomationScripts\BuildGraph\`.
```python
import ctypes, struct
from ctypes import c_void_p, c_ssize_t, c_int, create_string_buffer
f = ctypes.WinDLL(r"<path>\oo2core_9_win64.dll").OodleLZ_Decompress
f.restype = c_ssize_t
f.argtypes = [c_void_p, c_ssize_t, c_void_p, c_ssize_t, c_int, c_int, c_int,
              c_void_p, c_ssize_t, c_void_p, c_void_p, c_void_p, c_ssize_t, c_int]   # 14 arguments
raw, comp = struct.unpack_from("<ii", data, 0)
out = create_string_buffer(raw)
n = f(data[8:8+comp], comp, out, raw, 1, 0, 0, None, 0, None, None, None, 0, 3)     # n == raw
```
Without numpy and Pillow, you can compare images and write PNG in pure Python (`zlib` + `struct`). Comparing two 8K images takes about 24 s.

**Searching for names in Blueprint assets:** extract from the `.uasset` bytes the strings matching `[\x20-\x7e]{5,}`, because `strings.exe` is not available by default.

- **[source]** Headless Blueprint compile and resave of a mod's assets work without opening the editor window, and unlike `UnrealEditor-Cmd … -ExecCmds="Quit"` these commandlets exit on their own. Compile only the mod: `UnrealEditor-Cmd.exe <Project>\FactoryGame.uproject -run=CompileAllBlueprints -AllowListFile=<path relative to the project dir> -unattended -nullrhi -nosplash -abslog=<log>`; the allow list holds full object paths, one per line, matched exactly (`/<Mod>/Folder/Asset.Asset`), read in `UCompileAllBlueprintsCommandlet::ParseAllowList` as `FPaths::ProjectDir() + <path>`. It loads and compiles but never saves; the summary line is `Compiling Completed with N errors and M warnings and K blueprints that failed to load.` and the exit code is the error count. Resave every package of a folder: `-run=ResavePackages -PACKAGEFOLDER=<disk folder> -IgnoreChangelist -SKIPFAILS` (`ContentCommandlets.cpp`; without `-IgnoreChangelist` a package saved by a higher engine changelist than the local editor's is skipped). It saves all packages even when they log compile errors and then exits with code 1. Converts old UE4 assets (package legacy version `-7`) to the 5.6 format (legacy `-9`, UE5 file version `1017`). Evidence: ran both on a 65-asset Blueprint-only mod, 32–64 s per run, package headers read before and after. (2026-11-21, game 520140, SML 3.12.1, UE 5.6.1-CSS)
- **[source]** Resaving a Blueprint that references a class removed from the game drops that reference for good: cast nodes keep an empty target type ("This cast has an invalid target type (was the class deleted without a redirect?)"), a Blueprint whose parent class is gone keeps no parent ("has missing or NULL parent class"), and the class names disappear from the saved package's name table. Commit the unconverted assets first and read the original references from that commit when repairing. Evidence: name-table scan of the assets before and after `ResavePackages`. (2026-11-21, game 520140, SML 3.12.1, UE 5.6.1-CSS)
- **Blueprint graphs can be read without opening the editor window.** `UnrealEditor-Cmd.exe <Project>\FactoryGame.uproject -run=pythonscript -script=<file.py> -unattended -nullrhi` runs a Python script in the CSS editor and exits by itself (11 s for a mod with 65 assets). In the script, `unreal.AssetExportTask` with `object` set to the asset, `filename` ending in `.t3d`, `automated = True`, `prompt = False`, passed to `unreal.Exporter.run_asset_export_task(task)`, writes the whole Blueprint as text: every graph, node and pin with its links (`LinkedTo=(<node> <pin id>,)`), function references, default values, variables (`NewVariables(n)=...`) and the parent class. A few hundred lines of Python turn that text into readable pseudocode per graph (follow the exec pins, inline the pure nodes). In a commandlet the asset registry has not scanned the mod yet: `get_assets_by_path("/<Mod>", recursive=True)` returned 0 assets until `unreal.AssetRegistryHelpers.get_asset_registry().scan_paths_synchronous(["/<Mod>"], True)` was called first. The export also contains the compiler's copies of each graph (`<Function>_MERGED`, `ExecuteUbergraph_<Blueprint>`, function stubs that only call `ExecuteUbergraph_...`, `EdGraph_<n>` for expanded macros); skip them when reading. The commandlet's exit code is 1 when a loaded Blueprint has compile errors, although the export itself succeeded. Evidence: editor log `LogPython: EXPORT DONE ok=0 failed=0` without the scan and `ok=65 failed=0` with it; a 1.9 MB Blueprint asset gave 8.7 MB of text and 41 KB of pseudocode. (2026-11-21, UE 5.6.1-CSS, SML 3.12.1, editor commandlet)
- **A text export shows replicated Blueprint events that a name scan of the asset cannot see.** A custom event set to "Run on Server" appears in the T3D export as `FunctionFlags=203554880` on its `K2Node_CustomEvent` (`FUNC_Net | FUNC_NetServer | FUNC_Public | FUNC_BlueprintCallable | FUNC_BlueprintEvent`, no `FUNC_NetReliable`). A Blueprint-only mod that a scan of names in its `.uasset` files reported as having no RPC had four such events. Evidence: `grep -c FunctionFlags` over the exported files, 4 hits in two assets. (2026-11-21, UE 5.6.1-CSS, editor commandlet)
- **[source]** What a script can change in a Blueprint without the editor window: `unreal.BlueprintEditorLibrary` in 5.6.1-CSS (`Engine/Source/Editor/BlueprintEditorLibrary/Public/BlueprintEditorLibrary.h`) has `ReparentBlueprint`, `RemoveFunctionGraph`, `RemoveGraph`, `RemoveUnusedNodes`, `RemoveUnusedVariables`, `ReplaceVariableReferences`, `CreateBlueprintAssetWithParent`, `AddFunctionGraph`, `AddMemberVariable`, `CompileBlueprint`, `FindGraph` and `FindEventGraph`. There is no call that edits a single node or a link, so a broken node inside a graph is removed only together with its function or graph. Not run yet. (2026-11-21, UE 5.6.1-CSS)
- `CompileAllBlueprints` (and any commandlet) returns process exit code 1 whenever any error was logged (`LaunchEngineLoop.cpp`: `if ((ErrorLevel == 0) && (GWarn->GetNumErrors() > 0)) ErrorLevel = 1`), even when every Blueprint compiled. In a starter project without generated Wwise SoundBanks every run logs `LogWwiseProjectDatabase: Error: No JSON Metadata file found for platform … Have SoundBanks been generated?`, so the exit code is always 1. Judge the result by `Compiling Completed with 0 errors and 0 warnings and 0 blueprints that failed to load` and `Commandlet CompileAllBlueprintsCommandlet_0 finished execution (result 0)`, plus a count of `Compile of <BP> successful!` lines. `-AllowListFile=<path relative to the project folder>` limits the run to the mod's Blueprints. (2026-11-22, UE 5.6.1-CSS)
- `UnrealEditor-Cmd … -run=pythonscript -script="<path>.py <arg>"`: when the script gets an argument, backslashes in the script path are lost (`Could not load Python file 'D:UE…'`); use forward slashes. (2026-11-22, UE 5.6.1-CSS)
- Editor Python: setting `FSlateBrush.image_size` fails (`TypeError: Failed to convert type 'Vector2D' to property 'ImageSize'`); `resource_object` can be set and saved on a CDO brush. (2026-11-22, UE 5.6.1-CSS)
- Moving a Blueprint function to C++ without the editor window (Python in a commandlet: `BlueprintEditorLibrary.remove_function_graph`, then `reparent_blueprint` to a native class that declares a `UFUNCTION` with the same name): existing call nodes rebind to the native function by name and compile (`Compile of <BP> successful!`, then works in the packaged game). Conditions: the same pin names (a linked pin that becomes orphaned is a compile error, `K2Node::ValidateOrphanPin`), keep `__WorldContext` for library functions that had it (`meta=(WorldContext="__WorldContext")`), and do not make a `BlueprintCallable` member `const` if the old nodes had exec pins (a `const` `BlueprintCallable` becomes pure). **UMG property bindings do not rebind:** a widget property bound to the removed function becomes `Binding: 'None' : 'None' was not found` and the widget fails to compile; `WidgetBlueprint.Bindings` is protected and cannot be read or changed from Python, so the binding has to be redone in the editor (Details → property → binding button → Remove Binding, then the native function under Functions; native `BlueprintPure` functions of parent classes are listed). Evidence: compile logs, packaged game showing the bound title text. (2026-11-22, game 520140, UE 5.6.1-CSS)

**Hiding a plugin from the engine [source].** A plugin file named `<Mod>.uplugin.disabled` is not seen by UE or UBT, which look for the extension `.uplugin` (UBT `CppIncludeLookup.cs:260`). Docs say one broken mod folder can block packaging of every mod in the project, so rename the file and regenerate the project files instead of deleting the mod. (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)

**Reading the game's shipping DLL with `dumpbin`.** `dumpbin /exports <Game>\FactoryGame\Binaries\Win64\FactoryGameSteam-FactoryGame-Win64-Shipping.dll` lists the `FACTORYGAME_API` class members with their RVA, and `dumpbin /disasm` with the `.pdb` beside the DLL shows function names at call sites, which is enough to follow a native function the headers only declare. Run it from PowerShell (or cmd) with the MSVC tools on the path: Git Bash rewrites `/exports` and `/disasm` into paths. (2026-11-01, game 513885, MSVC 14.38)

**Git/GitHub**
- Check whether a commit applies cleanly to another branch (cherry-pick simulation without touching files):
  `git merge-tree --write-tree --merge-base=<commit>^ <branch> <commit>`
- Change a commit message without changing the content: `git commit-tree <sha>^{tree} -p <parent> -F -` (keep `GIT_AUTHOR_DATE`), then `git update-ref`, and finally `git diff old new` must be empty.
- Partial clone: `git clone --filter=blob:none --no-checkout --sparse -b <branch> <url>` and `git sparse-checkout set <path>`.
- Inspecting other people's forks:
  - `gh api repos/O/R/compare/A...B`,
  - `gh api "repos/O/R/commits?sha=<branch>"`,
  - `gh api repos/O/R/issues/<N>/timeline`: a "referenced" event means someone pushed a commit mentioning your PR.
- Drawing a layout from a log dump in PowerShell: `$Matches` is overwritten by every `-match`, also the one inside an `if` further down the loop, so copy it (`$m = $Matches`) right after the match you need, or a nested test like `$text -match 'platform'` silently loses the fields of the outer match (14 of 50 tracks vanished from a drawing that way). Numbers written into SVG with `"$x"` follow the current culture: a system with a decimal comma writes `12,5` and the SVG is invalid; set `[CultureInfo]::CurrentCulture = [CultureInfo]::InvariantCulture` at the top of the script or format with `.ToString([CultureInfo]::InvariantCulture)`. A quick preview of the SVG without a browser tool: `msedge --headless=new --disable-gpu --hide-scrollbars --window-size=W,H --screenshot=out.png file:///path.svg`. (2026-10-06, Windows 11, PowerShell 5.1, Edge)
- **[source]** The FicsIt-Networks reflection pages list game classes with their functions and properties, a quick reference before opening the headers (for example `RailroadSignal`, `domains/railroad/signals.md`).
- **Long scripts go into a file, not into a command line.** A long inline script failed in the shell (`ENAMETOOLONG: name too long, uv_spawn`; a Bash heredoc with a long Python script: `unexpected EOF while looking for matching`), the same in several sessions. Backslashes in a heredoc that feeds a Python string were also mangled (`\f` became a form feed). Write the script with the file tool and run the file. (2026-10-07, game 502094, SML 3.12.0)
- **A commit message written to a file by Windows PowerShell 5.1 can start with a byte-order mark** (`-Encoding utf8` writes one), which ends up at the start of the commit subject. Commit with `git commit -m`, or write the file without a BOM, and check `git log -1 --format=%B | head -c3 | od -An -tx1` is not `ef bb bf`. Evidence: two commits had to be redone after a sub-agent wrote the message files. (2026-10-03, game 502094, SML 3.12.0)
- **Windows PowerShell 5.1 does not expand a variable inside a native-command argument that starts with `-`.** `& RunUAT.bat -ScriptsForProject=$p PackagePlugin "-project=$p"` passed the literal `$p` to the first argument: UAT stopped with `Project '$p' does not exist relative to any entries in *.uprojectdirs`. With the whole argument in quotes (`"-ScriptsForProject=$p"`) the variable is expanded; a path written out needs no expansion. (2026-11-03, Windows PowerShell 5.1)
- **PowerShell: a helper function named `Git` that calls `git` inside calls itself**, because command names are case-insensitive and functions win over applications; the script then hangs until the call depth runs out (minutes, no error). A helper named differently (`Invoke-Git`) calling `git.exe` does not. Evidence: a check-only run that hung past 120 s finished in about 2 s after the rename. (2026-11-07, Windows PowerShell 5.1)
- **Windows PowerShell 5.1, a `[string]` parameter given a list.** Called with `& script.ps1 -C a,b` (also through `powershell -Command`), the array `a,b` bound to a `[string]` parameter arrives joined with a space, `"a b"`, so a later `-split ','` finds one value. Under `powershell -File script.ps1 -C a,b` the same parameter gets the literal text `"a,b"`. A parameter declared `[string[]]`, each element split on `,`, works under both. Evidence: a two-line test script printed `C=[a b]` under `-Command "& '<script>' -C a,b"` and `C=[a,b]` under `-File`. (2026-11-07, Windows PowerShell 5.1.26100)
- **Windows PowerShell 5.1 drops a bare `--` passed to a PowerShell function.** Inside `function f { $args.Count }`, `f a -- b` gives 2, `f a '--' b` gives 3. A wrapper around git (`function Invoke-Git { git.exe @args }`) called with `diff A B -- <paths>` therefore passes the paths with no separator; when one of them is missing from the tree, git exits 128 with no output, and a count of the output reads as "no changes". With the separator quoted (`'--'`) the call works; the exit code is in `$LASTEXITCODE`. Evidence: the same test script printed `args with bare --: 2` and `args with quoted --: 3`. (2026-11-07, Windows PowerShell 5.1.26100)
- **Windows PowerShell 5.1: `$PSScriptRoot` is empty in parameter defaults of an advanced script started with `-File`.** In an advanced script (one with `[Parameter(...)]` or `[CmdletBinding()]` on its `param` block) started with `powershell -File script.ps1`, `$PSScriptRoot` is empty inside parameter default values. It is set in the script body, and also in the defaults when the script is started with `& script.ps1` or through `-Command`. A default such as `"$PSScriptRoot\..\out.md"` then resolves against the drive root (`D:\out.md`). A path computed in the body (`if (-not $Out) { $Out = "$PSScriptRoot\..\out.md" }`) resolves correctly. Evidence: `param([Parameter(Mandatory)] [string] $T, [string] $P = "$PSScriptRoot\x")` printed `[\x]` under `-File` and the full path under `-Command "& '<script>' -T 1"`; without `[Parameter]` it printed the full path under `-File` too. (2026-11-07, Windows PowerShell 5.1.26100)
