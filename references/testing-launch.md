# Launch arguments and console options for test runs

Part of the `satisfactory-modding` skill. Markers: no marker = verified in practice, **[source]** = read from SML, game or engine code, not tested, **[?]** = uncertain. Replace the parts in `<...>` with your own. This file collects launch arguments beyond the ones in `references/testing.md`, "Launching the game for tests" (`-ini:` override, `-DisablePlugins`, `-windowed -ResX -ResY`, a custom test parameter). The test rules and the checklist stay in `references/testing.md`.

## Settings files

- **[source]** `-Multiprocess` stops the engine writing any `.ini` file. `AreWritesAllowedGlobally()` is false with `-Multiprocess` unless `-MultiprocessSaveConfig` is also given, and both ini writers check it (`<UE-CSS>/Engine/Source/Runtime/Core/Private/Misc/ConfigCacheIni.cpp:880-891, 2247`). A test run with it should therefore not rewrite `GameUserSettings.ini`, which would replace the copy and restore described in `references/testing.md` (rule 11 in `SKILL.md`). It was not run with the game: before dropping the copy, compare the file's hash before and after one run. SML's `Configs\<Mod>.cfg` files are JSON, not ini, so the switch does not cover them; keep the copy of those. The switch also skips the shader-directory cleanup (`LaunchEngineLoop.cpp:2857`). The docs use it only for a second local copy of the game, together with `-CustomConfig=` (which exists in the engine, `ConfigCacheIni.cpp:1287`; its effect in the game is **[?]**). (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)

## Console commands from the command line

- **[source]** `-ExecCmds="cmd1,cmd2 'arg,with,commas'"` works in Shipping through SML: a comma separates commands, single quotes protect commas inside an argument, and the commands are queued to `GEngine->DeferredCommands` after engine initialisation (`SML/Private/SatisfactoryModLoader.cpp:222-229`; the parser is `<UE-CSS>/Engine/Source/Runtime/Engine/Private/ParseExecCommands.cpp:11-70`). The engine's own `-Exec=` and `-ExecCmds` run only when `!UE_BUILD_SHIPPING` (`UnrealEngine.cpp:2234`). It can replace test code that sets console variables, for example `-ExecCmds="FG.AutosaveInterval 0,t.MaxFPS 30"`. Not run. (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)
- **[?]** Map options for the `LocalMapOptions` string beyond `skipOnboarding`, `listen` and `loadgame`. The docs list `?startloc=<PlayerStart tag>` (the hub is `TRADING_POST`), `?sessionName=`, `?DayLength=`, `?NightLength=`, `?allowPossessAny`, `?Visibility=SV_Private` and `?adminpassword=`, and say the page dates from 2021. A binary string search of the game's DLL found `allowPossessAny`, `startloc` and `DayLength` only as property names and no `adminpassword`, so none of them is confirmed. A custom level starts with `GameDefaultMap=/<Mod>/Maps/<L>/<L>.<L>` (docs). (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)

## Console window and rendering

- **[?]** The docs say that selecting text in the plain `-log` console window freezes the game until Enter is pressed, so a stray click in an unattended, timed run could stall it. `-log -NewConsole` opens the Unreal Console instead, which does not freeze and adds filters, checkpoint markers and a command line (also for a dedicated server). The `-NewConsole` switch is read in `<UE-CSS>/Engine/Source/Runtime/ApplicationCore/Private/Windows/WindowsPlatformApplicationMisc.cpp:53` **[source]**; the freeze itself is from the docs only. (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)
- **[?]** `-RenderOffScreen` renders without a window: no swap chain is created (`WindowsD3D12Viewport.cpp:33`, `GenericWindow.cpp`) and the switch is honoured by the Windows application layer and Slate (`WindowsPlatformApplicationMisc.cpp:77`, `SlateApplication.cpp:857`) **[source]**. The docs use it with `-norhithread` for the asset dumper. Unlike `-nullrhi`, which killed the client (`references/testing.md`, "The game client cannot run without a renderer"), the game still draws its UI, so it may be a lighter, hidden way to run tests. Not tried with the game; screenshots from such a run are untested. (2026-10-24, game 513885, SML 3.12.0, docs.ficsit.app)
